# Как протестировать бота

## 1. Получите токен бота

1. Откройте Telegram и найдите бота [@BotFather](https://t.me/botfather)
2. Отправьте команду `/newbot`
3. Следуйте инструкциям для создания нового бота
4. Скопируйте полученный токен

## 2. Настройте окружение

Создайте файл `.env` в директории `src/`:

```bash
cd src
cp .env.example .env
```

Откройте `.env` и добавьте ваш токен:

```env
TELEGRAM_BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
```

## 3. Запустите бота

```bash
go run ./cmd/bot
```

Вы должны увидеть:
```
Bot is starting...
Starting Telegram bot...
```

## 4. Протестируйте бота в Telegram

1. Найдите вашего бота в Telegram по username, который вы указали при создании
2. Отправьте боту любое сообщение, например: `Hello`
3. В логах терминала вы должны увидеть:
   ```
   Received message from user 123456789 in chat 123456789: Hello
   ```

## 5. Остановите бота

Нажмите `Ctrl+C` в терминале. Вы должны увидеть:
```
Bot stopped gracefully
```

## Что дальше?

Сейчас бот только логирует входящие сообщения. Следующие шаги:

1. **Добавить обработку команд** (`/start`, `/help`)
2. **Создать интерактивные клавиатуры**
3. **Реализовать логику тестирования**
4. **Добавить базу данных для хранения статистики**
5. **Добавить многоязычную поддержку**

## Отладка

### Проблема: "Failed to load config: TELEGRAM_BOT_TOKEN environment variable is required"

**Решение:** Убедитесь, что файл `.env` существует и содержит валидный токен.

### Проблема: Бот не отвечает на сообщения

**Решение:**
- Проверьте, что бот запущен
- Убедитесь, что вы написали правильному боту
- Проверьте логи в терминале

### Проблема: "Failed to create bot: Unauthorized"

**Решение:** Проверьте правильность токена в `.env` файле.
